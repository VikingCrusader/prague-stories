## 产品功能

- **历史事件独立链接 / 分享**：`/history/:slug` 或 `#slug`，每张卡配自己的 OG 预览图（用现有插画）。
- **主题步行路线**：如「胡斯与胡斯战争的布拉格」「查理四世的新城」，把时间线相关地点串成地图路线，走完解锁成就。
- **阅读也给奖励**：读完一个时代发徽章（例如「读完胡斯战争」），基于已有的阅读进度功能。
- **人物索引页（人物志）**：胡斯、杰士卡、查理四世等反复出场的人物，列出其出现过的所有事件。
- **时间线搜索 + 「五分钟读懂」时代概览卡**：按人名 / 地名搜索；每个时代一张概览卡，降低新读者门槛。 → 时代导览卡**已完成（2026-10-01）**，时代 1–5 各一张；搜索未做
- **离线可读**：利用已有的 `manifest.json` / `sw.js` 缓存时间线数据与图片。

## 工程与维护

- **拆分 seed 文件**：`seedHistoryEvents.js` ~3MB、`seedLocations.js` ~5MB，单文件易出错、读取费 token。按时代 / 地点拆分，由入口文件汇总，现有导入方式不变。
- **CLAUDE.md 瘦身**：插画规范、人物设计、各时代进度拆到 `docs/` 下单独文件，CLAUDE.md 只留核心规则与链接，节省每次对话的上下文。
- **基础安全**：服务器目前没有请求频率限制。登录 / 注册可被暴力尝试；Gemini 描述生成在 GET 请求中懒触发，可能被刷产生费用。加 `express-rate-limit`。
